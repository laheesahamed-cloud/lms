Every tool looks identical. Lessons, ECG, Auscultation, Planner — 7 rows in a row, every icon the same blue chip on the same dark card. Nothing tells you these are different tools until you read the text.
It's a settings list, not a launcher. Icon → title → subtitle → chevron, repeated 7 times top to bottom — the same pattern iOS uses for "Settings," not for the screen students open most.
The one tool with real stats (Drugs) still looks like the rest. It already tracks spins and readiness — that data just sits inside the same plain card as everything else, so it doesn't stand out as the featured tool it is.
Drugs and My Notes both get featured treatment. Drugs already had live stats; My Notes is where students create their own content — both earn top billing instead of blending into row 4 and row 7 of a list.
One color per remaining tool, from the seven DashAccents already in your tokens. Lessons=cyan, Flashcards=violet, ECG=rose, Auscultation=green, Planner=amber, Saved=blue — you can tell tools apart at a glance, before reading a word.
Option 1 vs Option 2 is a height/density trade-off. Stacked (1) gives each featured tool more room and a live stat bar; side-by-side (2) is more compact but each card can show less.
List becomes a 2-up grid. 7 tall rows become a compact grid that fits in less than one screen of scrolling — it reads like a launcher, not a settings menu.
Drugs becomes the actual featured hero. Same spin-count and ready-state data, now in a bold gradient card above the grid — the one tool with live stats finally looks like the featured one.
Mockup only — built from the real tools and colors already in study_hub_page.dart and theme/tokens.dart. Nothing here is implemented yet; say the word and it gets built into the actual Flutter screen.
